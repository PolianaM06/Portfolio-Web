# 💜 Meu Portfólio Web

Bem-vindo(a) ao repositório do meu portfólio de desenvolvimento web!

Este projeto foi desenvolvido para apresentar meus projetos, demonstrar minhas habilidades técnicas e compartilhar minha evolução como desenvolvedora. O site reúne trabalhos desenvolvidos durante meus estudos e projetos pessoais, colocando em prática os conhecimentos adquiridos em desenvolvimento front-end.

🔗 **Acesse meu portfólio:** [Visualizar site](https://polianam06.github.io/Portfolio-Web/)

---

## ✨ Funcionalidades

- **Apresentação pessoal:** informações sobre mim e minha trajetória na área de tecnologia.
- **Projetos:** apresentação dos meus projetos de desenvolvimento web.
- **Design responsivo:** interface adaptada para diferentes tamanhos de tela.
- **Navegação intuitiva:** organização do conteúdo em seções para facilitar a experiência do usuário.
- **Interatividade:** funcionalidades implementadas com JavaScript.
